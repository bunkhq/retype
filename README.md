# Retype

A macOS app for switching a file to a neighbouring format. Drop a file, move through the formats it can become, and click one. Files never leave the Mac. When the codecs already fit (mp4 to mov, mkv to mp4), Retype changes the container without re-encoding.

**Status:** brand direction chosen. The app is not built yet.
